NOSSO LAR — VERSÃO 14

Atualizações desta versão:
1. Gráfico “Despesas por categoria” mais compacto para aproveitar melhor o espaço da tela inicial.
2. Despesas não pagas com vencimento anterior à data atual são destacadas em vermelho em “Próximos lançamentos”, com indicação “Vencida”.
3. Removida a seção “Como funciona o controle da casa”. O “Resumo do mês” foi reorganizado em indicadores compactos, com saldo previsto e receitas em destaque.
4. Menu lateral modernizado com ícones em fundos suaves, realce da opção selecionada e espaçamento aprimorado.

As funcionalidades anteriores da versão 13 foram mantidas. O service worker usa uma nova chave de cache para facilitar a atualização publicada.

PUBLICAÇÃO
- Faça backup JSON dos dados antes de substituir arquivos.
- Extraia todos os arquivos do ZIP para a raiz do repositório GitHub Pages, substituindo os arquivos de mesmo nome.
- Mantenha a mesma URL para preservar o acesso aos dados salvos no navegador.
- Após publicar, recarregue o sistema. Não limpe os dados do Safari.

Observação: a validação realizada nesta entrega inclui sintaxe JavaScript e integridade do ZIP. Testes funcionais no Safari/iPad devem ser feitos após a publicação.
