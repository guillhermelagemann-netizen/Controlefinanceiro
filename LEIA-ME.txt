NOSSO LAR — PACOTE CORRIGIDO (2026-10-13-r7)

IMPORTANTE: este ZIP contém os arquivos diretamente na raiz. NÃO envie o ZIP inteiro para o GitHub Pages. Extraia primeiro e envie os ARQUIVOS que estão dentro dele para a raiz do repositório.

ARQUIVOS A PUBLICAR NA RAIZ DO REPOSITÓRIO:
- index.html
- sw.js
- manifest.webmanifest
- icon-192.png
- icon-512.png

PASSOS DE ATUALIZAÇÃO PELO IPAD:
1. Faça o backup JSON dentro do Nosso Lar e confirme que o arquivo está no app Arquivos.
2. Baixe e extraia este ZIP no app Arquivos.
3. Abra o repositório no GitHub pelo Safari.
4. Na raiz do repositório (a mesma pasta onde já existe o index.html), use Add file / Upload files e envie os cinco arquivos acima. Se perguntarem sobre substituição, confirme. Não crie uma subpasta.
5. Faça Commit changes e aguarde o GitHub Pages publicar.
6. Abra o endereço público do site no Safari. Feche a aba anterior primeiro. Recarregue a página; se o iPad mostrar o ícone do app instalado, abra o site no Safari normal para testar a versão nova.

O QUE ESTA VERSÃO INCLUI:
- Campo Dinheiro guardado no Início.
- Menu separado Análise de cartões.
- Importação de PDF com extração de texto selecionável, revisão das compras e comparativo por cartão/mês.
- Cache v7 com atualização do HTML pela rede e fallback offline.

LIMITAÇÕES:
- A extração das compras é aproximada e precisa de revisão; PDFs escaneados como imagem não têm OCR embutido.
- O leitor PDF.js precisa de internet para carregar na primeira utilização.
- Os dados são salvos no armazenamento local do navegador. O backup JSON é essencial; não há sincronização entre dispositivos.
- Compras detalhadas importadas não são somadas novamente às despesas gerais.
