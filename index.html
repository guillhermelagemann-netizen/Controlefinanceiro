Importar arquivo mensal de cartões

Use este importador para carregar o arquivo JSON revisado mensalmente. Ele registra uma fatura por banco e adiciona os lançamentos detalhados sem somá-los novamente às despesas. Antes de importar, faça backup dos dados. O sistema evita duplicar uma fatura com o mesmo banco, cartão e mês.

Importar fatura em PDF

O PDF é lido neste navegador. O sistema sugere tipos por banco/descrição e tenta identificar o total da fatura. A classificação é uma sugestão: revise e concilie antes de salvar; layouts variam entre bancos. PDFs digitalizados como imagem podem não ter texto extraível. O arquivo não é enviado ao site.

Tipos aceitos: compra, encargo, credito, pagamento, informativo. Só “compra” entra no gráfico de utilização. Encargos/créditos ficam separados para conferência.

Comparativo visual dos cartões

Compare os gastos por banco e por mês. Os gráficos consideram somente lançamentos classificados como compras. Encargos, créditos e pagamentos ficam separados; confira a conciliação de cada fatura.

Configurações
Backup e cuidados com os dados do Nosso Lar.
Backup dos seus dados
Os registros ficam no armazenamento local deste navegador e não são enviados ao GitHub Pages. Se você limpar os dados do Safari, trocar de navegador ou de dispositivo, os lançamentos podem não estar disponíveis. Exporte um backup JSON regularmente e guarde-o em local seguro.
A importação substitui os registros atuais após confirmação. Não compartilhe seu backup financeiro com outras pessoas.
Regras do controle
• Despesas fixas aparecem nos meses seguintes até serem desativadas.
• Parcelamentos geram uma parcela por mês até completar a quantidade informada.
• Compras detalhadas da fatura são apenas informativas e não são somadas novamente ao total da fatura.
• Marcar um lançamento como pago altera somente seu status.
